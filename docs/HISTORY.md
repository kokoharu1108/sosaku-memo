# 要望と対応の経緯

claude.ai での開発（2026年10月）のやり取りを、版ごとにまとめたもの。番号は `sw.js` の `CACHE` の版数に対応。

## 前史: claude.ai 上の試作版

- 仕様書と画面遷移図から、claude.ai のアーティファクト（Webページ）として最初の版を作成。メモ検索・閲覧・作成・管理、リスト、参照メモ、AI検索パネル、自動保存、0時の整理、ダークモード切替を実装。
- 利用者の質問「ホーム画面から開けるか」「オフラインで使えるか」を受け、**GitHub Pages で公開する PWA** に作り替えることに決定。保存先は端末内（IndexedDB）、同期なし、バックアップの書き出し／読み込み機能付き。

## v1〜v2

- PWA 化（manifest、Service Worker、アイコン）。オフライン起動・保存・閲覧を確認。
- AI検索は利用者のAPIキー（Claude / Gemini）を設定する方式に。Gemini の標準モデルを `gemini-3.8-flash` に更新（2.5 は新規利用が制限されていたため）。

## v3

- AI検索を「Wikipedia 要約＋外部検索（Google・画像・辞書）＋APIキー登録時のみAI」に作り替え。
- リストを開いた画面から保存済みメモを選んで追加できるように。
- 右下の＋ボタンをタブに応じて「新規メモ／新規リスト」に統一。
- 箇条書きの点が消せない不具合を修正（ボタン再押下・行頭Backspaceで解除）。
- 反応のない「書式をクリア」ボタンを削除。

## v4

- 調べるパネルを開閉すると画面サイズが崩れる不具合を修正（閲覧画面を画面固定、本文のみスクロール）。
- 「調べる」つまみの位置を固定。
- 閲覧画面の重複した「編集」ボタンを削除（⋯メニューに一本化）。
- 検索画面にジャンル絞り込みを追加。
- リストはタブのない専用画面で開くように。
- 選択時の「調べる」ボタンを画面下部へ（スマホのコピー等のメニューと重なるため）。

## v5

- 本文の画像サイズを変更可能に（タップ→小/中/大/全幅・スライダー）。閲覧画面では画像タップで全体表示→もう一度で原寸。
- 文字サイズ変更ボタンを撤廃。
- 画面上部に現在地のパンくず表示。
- Android の戻る操作（画面端からのスワイプ）に対応。画像拡大や確認ウィンドウが開いていれば先に閉じる。未保存の編集は確認。
- 「創作メモ帳」タップで最初の画面へ。
- ジャンル絞り込みをプルダウンに。
- **「調べる」機能を全面撤廃**（スマホ標準の選択メニューで Web 検索できるため）。
- 追加機能を提案（体験日の記録、五感テンプレート、ふりかえり表示、自由タグ、逆参照）。

## v6

- **自由タグ**（入力候補つき、閲覧画面のタグタップで同タグ検索）と**ふりかえり表示**（n年前の今日／1週間以上前のメモ、「別のメモ」「今日は表示しない」）を追加。
- 作成日時と更新日時を分けて記録・表示。並び順も作成／更新を選べるように。
- バックアップを促す表示を削除（設定に前回の書き出し日時と、保存の保護状態を表示）。
- 検索窓・絞り込みをスクロールしても上部に固定。
- リストタブの「null」表示を修正。
- 画面ごとに上部バーの色を変更（閲覧=青緑、リスト=藤色、編集=生成り）。
- メモの選択モード（まとめて削除、リスト画面では「リストから外す」も）。

## v7

- 保存済みメモを編集して保存したら、1つ前の画面に戻るように。
- ダークモード切替を設定内へ。
- 閲覧画面の添付ファイルを折りたたみの一覧に。タップで中身確認（画像・テキスト・動画・音声はアプリ内、PDF は別画面、その他は端末に保存）。
- 利用者の質問「Googleドライブに直接保存できないか」→ オフラインで使えなくなるため非推奨と回答。「端末保存＋裏で自動同期」を代替案として提示（未着手）。

## v8

- 検索窓・絞り込みを右上の🔍ボタンで開閉するパネルに集約。
- **参照機能を Confluence 風の階層（ツリー）に作り替え**（`parentId`）。閲覧画面に階層パスと「下の階層のメモ」、検索画面に「ツリー」タブ。既存の参照は「AがBを参照→BをAの子」として自動移行。
- 本文に見出し（見出し1〜3）とマーカーを追加。
- 文字色をテーマ対応のクラス方式に（ダークモードで黒くなる不具合の修正）。
- 書式ボタンに選択中の状態を表示。
- スマホで本文入力中、書式ツールバーをキーボード上に固定。
- 太字等が保存時に消える不具合、日本語入力直後の書式で文字順が入れ替わる不具合を修正。

## v9

- 検索履歴が絞り込みを隠す問題 → 検索窓の下に横並びのボタンで表示。
- ツリータブは「下の階層を持つ最上位メモ」のみを閉じた状態で表示。メモ名タップで開閉、右端「›」で開く。
- 見出し等の小窓が画面外に出る不具合を修正（CSS の上書き漏れで `position: absolute` のままだった）。
- 太字・斜体など複数書式の付け外しの不具合を修正（`restoreRange` が選択状態を毎回リセットしていた）。カーソルのみの状態は自前の `toggleInline` で処理。
- 調査で発見: カーソル位置で色を選ぶと仮の色で固定される／`https://` 省略のリンクが入らない／日本語変換中の書き換え／空の書式要素が残る — いずれも修正。

## v10

- 上部バーの彩度を上げ、屋外でも画面を見分けやすく（最初の画面=水色、閲覧=ミント、リスト=藤色、編集=杏色。ダークモードも同じ色相で濃いめ）。最初の画面にもバー色を付けた。
- スマホ上端の帯（時計などが並ぶ部分）の色も、いまの画面のバー色に合わせて変わるように。アプリ内でダークモードに切り替えたときも追従。
- 調査で発見・修正:
  - 編集中にパンくずの「創作メモ帳」を押すと、未保存の変更が確認なしで消えていた → 確認を出す。
  - 新しいメモを保存すると常に最初の画面へ戻っていた（リスト画面や親メモから作っても）→ 1つ前の画面に戻る。
  - 選択モードのままパンくずで戻ると、その後スマホの「戻る」操作が効かなくなっていた → 修正。
  - 削除済みのメモの編集画面が履歴に残っていた場合、1つ前ではなく最初の画面が出ていた → 1つ前の画面へ。
  - 更新時に Service Worker がブラウザの一時保存から古い版を取り込むことがあった → 必ずサーバーから取り直す。

## v11

- 新規メモ画面の本文より上がごちゃごちゃして扱いづらい → 本文より上は「題名」と「ジャンル」（1行）だけに。タグ・階層・リストは本文と添付の下の「そのほかの設定（あとからでもOK）」へ移動。直近の題名は題名欄を触っている間だけ1行で表示。書式ボタンはスマホ幅でも1行に収まるように。
- 調査で発見・修正:
  - メモを削除すると常に最初の画面へ戻っていた → 1つ前の画面（リストや親メモ）に戻る。
  - 削除したメモの画面を飛ばして戻ったあと、スマホの「戻る」操作が1回空振りしていた → 履歴を合わせて戻るように。
  - アプリ更新のたびに保存済みのフォントが消え、更新直後にオフラインだと文字の形が変わっていた → フォントは版をまたいで残す。
- CLAUDE.md に「毎回、不具合調査を行い発見次第修正する」を追記。
