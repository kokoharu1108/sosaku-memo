# 要望と対応の経緯

claude.ai での開発（2026年10月）のやり取りを、版ごとにまとめたもの。番号は `sw.js` の `CACHE` の版数に対応。

## 前史: claude.ai 上の試作版

- 仕様書と画面遷移図から、claude.ai のアーティファクト（Webページ）として最初の版を作成。メモ検索・閲覧・作成・管理、リスト、参照メモ、AI検索パネル、自動保存、0時の整理、ダークモード切替を実装。
- 利用者の質問「ホーム画面から開けるか」「オフラインで使えるか」を受け、**GitHub Pages で公開する PWA** に作り替えることに決定。保存先は端末内（IndexedDB）、同期なし、バックアップの書き出し／読み込み機能付き。

## v1〜v2

- PWA 化（manifest、Service Worker、アイコン）。オフライン起動・保存・閲覧を確認。
- AI検索は利用者のAPIキー（Claude / Gemini）を設定する方式に。Gemini の標準モデルを `gemini-3.8-flash` に更新（2.5 は新規利用が制限されていたため）。

## v3

- AI検索を「Wikipedia 要約＋外部検索（Google・画像・辞書）＋APIキー登録時のみAI」に作り替え。
- リストを開いた画面から保存済みメモを選んで追加できるように。
- 右下の＋ボタンをタブに応じて「新規メモ／新規リスト」に統一。
- 箇条書きの点が消せない不具合を修正（ボタン再押下・行頭Backspaceで解除）。
- 反応のない「書式をクリア」ボタンを削除。

## v4

- 調べるパネルを開閉すると画面サイズが崩れる不具合を修正（閲覧画面を画面固定、本文のみスクロール）。
- 「調べる」つまみの位置を固定。
- 閲覧画面の重複した「編集」ボタンを削除（⋯メニューに一本化）。
- 検索画面にジャンル絞り込みを追加。
- リストはタブのない専用画面で開くように。
- 選択時の「調べる」ボタンを画面下部へ（スマホのコピー等のメニューと重なるため）。

## v5

- 本文の画像サイズを変更可能に（タップ→小/中/大/全幅・スライダー）。閲覧画面では画像タップで全体表示→もう一度で原寸。
- 文字サイズ変更ボタンを撤廃。
- 画面上部に現在地のパンくず表示。
- Android の戻る操作（画面端からのスワイプ）に対応。画像拡大や確認ウィンドウが開いていれば先に閉じる。未保存の編集は確認。
- 「創作メモ帳」タップで最初の画面へ。
- ジャンル絞り込みをプルダウンに。
- **「調べる」機能を全面撤廃**（スマホ標準の選択メニューで Web 検索できるため）。
- 追加機能を提案（体験日の記録、五感テンプレート、ふりかえり表示、自由タグ、逆参照）。

## v6

## v21

- 事故: v20 の案内で「ホーム画面から削除して入れ直してもメモは消えない」と伝えたが、**iPhone ではホーム画面のアプリを削除すると中のメモも消える**（Android の Chrome とは違う）。利用者のメモが消えてしまった。→ CLAUDE.md に注意を記録。
- 再発防止として **Googleドライブ同期** を追加（GAS 方式。利用者の希望で「同期」ボタンを押したときだけオン、もう一度押すまでオンのまま）。オン中は保存のたびに自動送信、起動時・電波復帰時にも同期。複数端末は「新しい方を残す」、削除も反映、添付ファイルも送受信。入れ直した端末では同じ URL と合言葉で「同期」を押すと戻る。ドライブには毎日の控えを30日分。
  - 設定画面: 「Googleドライブ同期」を「バックアップ」の上に。バックアップの説明に iPhone の注意を追記。
  - 新しいファイル: `gas/Code.gs`（利用者が Apps Script に貼る）、`docs/Googleドライブ同期の設定.md`（手順）、`tests/fake_gas.py`（テスト用）。
- 調査で発見・修正: リストにメモを出し入れしたとき、メモの更新日時が変わらず、同期で古い内容に戻ってしまう可能性があった → 出し入れしたメモの更新日時も進める。

## v23

- 同期で「接続先が見つかりません」（URL は /exec まで確認済み）との報告。外から確認できないため、考えられる原因に対処:
  - 複数の Google アカウントでログイン中にコピーした「/macros/u/1/s/…」、会社などのアカウント（Google Workspace）の「/a/macros/ドメイン/s/…」の形は、ログインしていないアプリからは見つからない → アプリが自動で「/macros/s/…/exec」に直す（保存済みのURLも）。
  - テスト用の「/dev」URLは入力時に案内。
