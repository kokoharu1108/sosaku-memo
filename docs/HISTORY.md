# 要望と対応の経緯

claude.ai での開発（2026年10月）のやり取りを、版ごとにまとめたもの。番号は `sw.js` の `CACHE` の版数に対応。

## 前史: claude.ai 上の試作版

- 仕様書と画面遷移図から、claude.ai のアーティファクト（Webページ）として最初の版を作成。メモ検索・閲覧・作成・管理、リスト、参照メモ、AI検索パネル、自動保存、0時の整理、ダークモード切替を実装。
- 利用者の質問「ホーム画面から開けるか」「オフラインで使えるか」を受け、**GitHub Pages で公開する PWA** に作り替えることに決定。保存先は端末内（IndexedDB）、同期なし、バックアップの書き出し／読み込み機能付き。

## v1〜v2

- PWA 化（manifest、Service Worker、アイコン）。オフライン起動・保存・閲覧を確認。
- AI検索は利用者のAPIキー（Claude / Gemini）を設定する方式に。Gemini の標準モデルを `gemini-3.8-flash` に更新（2.5 は新規利用が制限されていたため）。

## v3

- AI検索を「Wikipedia 要約＋外部検索（Google・画像・辞書）＋APIキー登録時のみAI」に作り替え。
- リストを開いた画面から保存済みメモを選んで追加できるように。
- 右下の＋ボタンをタブに応じて「新規メモ／新規リスト」に統一。
- 箇条書きの点が消せない不具合を修正（ボタン再押下・行頭Backspaceで解除）。
- 反応のない「書式をクリア」ボタンを削除。

## v4

- 調べるパネルを開閉すると画面サイズが崩れる不具合を修正（閲覧画面を画面固定、本文のみスクロール）。
- 「調べる」つまみの位置を固定。
- 閲覧画面の重複した「編集」ボタンを削除（⋯メニューに一本化）。
- 検索画面にジャンル絞り込みを追加。
- リストはタブのない専用画面で開くように。
- 選択時の「調べる」ボタンを画面下部へ（スマホのコピー等のメニューと重なるため）。

## v5

- 本文の画像サイズを変更可能に（タップ→小/中/大/全幅・スライダー）。閲覧画面では画像タップで全体表示→もう一度で原寸。
- 文字サイズ変更ボタンを撤廃。
- 画面上部に現在地のパンくず表示。
- Android の戻る操作（画面端からのスワイプ）に対応。画像拡大や確認ウィンドウが開いていれば先に閉じる。未保存の編集は確認。
- 「創作メモ帳」タップで最初の画面へ。
- ジャンル絞り込みをプルダウンに。
- **「調べる」機能を全面撤廃**（スマホ標準の選択メニューで Web 検索できるため）。
- 追加機能を提案（体験日の記録、五感テンプレート、ふりかえり表示、自由タグ、逆参照）。

## v6

- **自由タグ**（入力候補つき、閲覧画面のタグタップで同タグ検索）と**ふりかえり表示**（n年前の今日／1週間以上前のメモ、「別のメモ」「今日は表示しない」）を追加。
- 作成日時と更新日時を分けて記録・表示。並び順も作成／更新を選べるように。
- バックアップを促す表示を削除（設定に前回の書き出し日時と、保存の保護状態を表示）。
- 検索窓・絞り込みをスクロールしても上部に固定。
- リストタブの「null」表示を修正。
- 画面ごとに上部バーの色を変更（閲覧=青緑、リスト=藤色、編集=生成り）。
- メモの選択モード（まとめて削除、リスト画面では「リストから外す」も）。

## v7

- 保存済みメモを編集して保存したら、1つ前の画面に戻るように。
- ダークモード切替を設定内へ。
- 閲覧画面の添付ファイルを折りたたみの一覧に。タップで中身確認（画像・テキスト・動画・音声はアプリ内、PDF は別画面、その他は端末に保存）。
- 利用者の質問「Googleドライブに直接保存できないか」→ オフラインで使えなくなるため非推奨と回答。「端末保存＋裏で自動同期」を代替案として提示（未着手）。

## v8

- 検索窓・絞り込みを右上の🔍ボタンで開閉するパネルに集約。
- **参照機能を Confluence 風の階層（ツリー）に作り替え**（`parentId`）。閲覧画面に階層パスと「下の階層のメモ」、検索画面に「ツリー」タブ。既存の参照は「AがBを参照→BをAの子」として自動移行。
- 本文に見出し（見出し1〜3）とマーカーを追加。
- 文字色をテーマ対応のクラス方式に（ダークモードで黒くなる不具合の修正）。
- 書式ボタンに選択中の状態を表示。
- スマホで本文入力中、書式ツールバーをキーボード上に固定。
- 太字等が保存時に消える不具合、日本語入力直後の書式で文字順が入れ替わる不具合を修正。

## v9

- 検索履歴が絞り込みを隠す問題 → 検索窓の下に横並びのボタンで表示。
- ツリータブは「下の階層を持つ最上位メモ」のみを閉じた状態で表示。メモ名タップで開閉、右端「›」で開く。
- 見出し等の小窓が画面外に出る不具合を修正（CSS の上書き漏れで `position: absolute` のままだった）。
- 太字・斜体など複数書式の付け外しの不具合を修正（`restoreRange` が選択状態を毎回リセットしていた）。カーソルのみの状態は自前の `toggleInline` で処理。
- 調査で発見: カーソル位置で色を選ぶと仮の色で固定される／`https://` 省略のリンクが入らない／日本語変換中の書き換え／空の書式要素が残る — いずれも修正。

## v10

- 上部バーの彩度を上げ、屋外でも画面を見分けやすく（最初の画面=水色、閲覧=ミント、リスト=藤色、編集=杏色。ダークモードも同じ色相で濃いめ）。最初の画面にもバー色を付けた。
- スマホ上端の帯（時計などが並ぶ部分）の色も、いまの画面のバー色に合わせて変わるように。アプリ内でダークモードに切り替えたときも追従。
- 調査で発見・修正:
  - 編集中にパンくずの「創作メモ帳」を押すと、未保存の変更が確認なしで消えていた → 確認を出す。
  - 新しいメモを保存すると常に最初の画面へ戻っていた（リスト画面や親メモから作っても）→ 1つ前の画面に戻る。
  - 選択モードのままパンくずで戻ると、その後スマホの「戻る」操作が効かなくなっていた → 修正。
  - 削除済みのメモの編集画面が履歴に残っていた場合、1つ前ではなく最初の画面が出ていた → 1つ前の画面へ。
  - 更新時に Service Worker がブラウザの一時保存から古い版を取り込むことがあった → 必ずサーバーから取り直す。

## v11

- 新規メモ画面の本文より上がごちゃごちゃして扱いづらい → 本文より上は「題名」と「ジャンル」（1行）だけに。タグ・階層・リストは本文と添付の下の「そのほかの設定（あとからでもOK）」へ移動。直近の題名は題名欄を触っている間だけ1行で表示。書式ボタンはスマホ幅でも1行に収まるように。
- 調査で発見・修正:
  - メモを削除すると常に最初の画面へ戻っていた → 1つ前の画面（リストや親メモ）に戻る。
  - 削除したメモの画面を飛ばして戻ったあと、スマホの「戻る」操作が1回空振りしていた → 履歴を合わせて戻るように。
  - アプリ更新のたびに保存済みのフォントが消え、更新直後にオフラインだと文字の形が変わっていた → フォントは版をまたいで残す。
- CLAUDE.md に「毎回、不具合調査を行い発見次第修正する」を追記。

## v12

- 修正の流れを「PR作成 → 自動確認（CI）→ 問題なければ自動でマージ」に変更。PR のたびに GitHub Actions で、JavaScript の書き間違い・版番号の上げ忘れ・スマホ幅での主要操作を自動確認する。
- 調査で発見・修正: 設定画面でバックアップを書き出しても「前回の書き出し」が古いままだった／書き出し完了の表示がなかった／ボタンの連打で二重に書き出せた → いずれも修正。

## v13

- **情報まとめ機能を追加**（仕様書に追記）。メモ検索に組み込み、検索・絞り込み結果とリスト画面の「📄 まとめる」から、該当メモの文章・画像・ファイルを1つのレポートにまとめる。表紙（件数・期間・ジャンル内訳・よく出るタグ）、目次、ジャンル別／日付順の本文、キーワード強調。本文は「関連部分だけ／全文」、画像の有無を切り替え可。「ファイルに保存」（画像入りの1つのHTML、オフラインで開け印刷・PDF化できる）、「印刷・PDF」、「共有」。検索対象に添付ファイル名も追加。
  - 新規機能ではなく検索に組み込んだ理由: 条件指定（キーワード・ジャンル）が検索と同じで、まとめる前に結果一覧で中身を確認できるため。リストからも作れるようにした。
- マーカーの確認: 文字を選んでマーカーを付けるのは正常。ただし**「なし」で外しても色が残る**不具合があった（文字色の「標準」も条件によって同様）→ 選んだ部分だけ正しく外れるように修正。カーソルだけの状態で「なし」を選んだ場合も、以降の文字は色なしになる。太字などの付け外しは正常を確認。
- 添付ファイルの「ドロップ」表記をやめ、「📎 写真・ファイルを追加」ボタンに。
- 画面に固定されるバー（上部バー・編集画面下の保存バー・選択モードの下部バー）をすべて画面ごとの色に。上部バーの半透明もやめ、スクロールしても色が薄くならないように。

## v14

- 検索画面の右上（選択ボタンの左）に「null」と出ていた → 修正（キーワードなしのとき、出さないボタンの代わりに「null」という文字が入っていた）。
- 検索画面の「選択」を、上部の固定バー（タブの行の右端）へ移動。
- 「まとめる」の出力が分かりにくい → まとめを「抜き出した情報だけでできた1つの新しいメモ」として作り直し。元メモの題名・日付・タグ・目次・件数の表などは出さず、「体験／学び／アイデア」ごとの箇条書き＋画像＋添付ファイルのすっきりした構成に。「新しいメモとして保存」（下書きとして開き、手直しして保存）を追加。並べ方の切り替えは廃止。
- 調査で発見・修正: 続けて保存すると「保存完了」の表示が何個も重なり、上部バーを隠していた → 常に最新の1件だけ表示。

## v15

- 検索画面などがごちゃついて見にくい → 情報量を整理。
  - 「まとめる」「選択」「リスト名の変更」「リストの削除」「設定」「ファイルに保存」「印刷・PDF」「共有」をアイコンに。
  - メモのカードを「題名・作成日／本文の冒頭2行／ジャンル・タグ2つ・添付数」だけに（時刻・リスト名・3つ目以降のタグは出さない）。件数は「3件」だけ。
  - リスト画面: まとめる・選択・名前変更を上部バーのアイコンに移し、本文側は「件数・絞り込み」の1行＋「保存済みのメモを入れる」だけに。
  - メモ閲覧画面: 日付を1行に、ジャンル・リスト・タグを1行に。
- まとめの「ファイルに保存」が毎回同じファイル名で上書きされる → ファイル名に保存時刻（秒まで）を付けて毎回別名に。
- ツリー機能を廃止（ツリーのタブ、閲覧画面の「下の階層のメモ」と「子メモを作成」、編集画面の「階層（このメモの親）」）。親子のデータ自体は残している。

## v16

- まとめのファイル名: 秒までは不要との指摘 → 「まとめの題名_日付」（例：夏のまとめ_20261003.html）に戻した。同じ日に同じまとめを保存し直した場合の上書きは利用者の想定どおりで問題なし。
- 調査: ダークモードでのアイコン表示・リスト画面・選択モードを確認し、新たな不具合はなし。

## v17

- まとめ画面の「新しいメモとして保存」が長い → アイコン付きの「メモにする」に短縮。
- まとめ画面のダウンロード・印刷・共有アイコンがスマホでズレる（共有が次の行に落ちていた）→ 1行に収まるように。
- 検索パネルをスマホの戻る操作（画面端からのスワイプ）で閉じられるように（開くと履歴を1つ積む）。
- 検索画面の文字が小さい → 「最近」「絞り込み」・件数・履歴・カード本文・ジャンル・タグ・タブなどを大きく。検索履歴は直近3件のみ（4件目以降は自動削除）、「消去」ボタンは撤廃。
- メモ1件ごとの境界が分かりにくい → カードの左端にジャンル色の帯、枠をはっきり・影を付け、間隔も少し広く。
- CLAUDE.md に「修正後は全画面で UI・情報量が過多になっていないか確認し、必要なら直す」を追記。
- 全画面の見直し: メモ編集画面の項目名、設定画面の説明文、リスト一覧の件数表示も小さかったので大きく。
- 調査で発見・修正: 検索パネルを開いたまま、パンくずで最初の画面に戻ると、その後の「戻る」が1回空振りする → 起きないように。

## v18

- ダークモードの色合いを屋外向けに見直し: 画面ごとのバーの色が本体の背景とほとんど同じ明るさで見分けにくかった → 色を濃く・明るくして、背景との差を約2倍に。バーの上の文字・アイコンも明るく。日付や補足などの薄い文字が暗すぎた → 明るく。（明るい表示の薄い文字も薄すぎたので少し濃く）
- まとめを作成日時の期間で作れるように（今日／昨日／過去7日間／今月／先月／今年／日付を指定）。キーワードなしでも「まとめる」を押せるように。題名は条件から自動で付く。
- メモ画面下部の「そのほかの設定（あとからでもOK）」「（自由に付けられます）」を削除、「リストに入れる」→「リスト」。
- 調査で発見・修正: リストから開いたまとめ画面で、パンくずがリスト名を2回表示して長くなり、先頭の「創作メモ帳」が隠れていた → 「まとめ」だけに。

## v19

- まとめで、本文中の画像を関連する文章と一緒に表示（例：「▼タイの写真」の下の写真はその行と同じ項目に）。「メモにする」でも同じ位置に入る。本文に入っていない添付画像だけを末尾の「画像」に。
- まとめ画面でリストを選べるように（キーワード・期間と組み合わせ可）。
- 検索画面のメモ／リストのタブを、画面の横スライドで切り替えられるように（画面の端から始まる操作はスマホの「戻る」なので反応しない）。
- メモ画面: 「よく使うタグ：」の文字をタグのアイコンに変え、候補を1行に。リストはプルダウンで選び、選んだリストは✕で外せる（プルダウンの最後から新しいリストも作れる）。題名欄の「（空欄でもOK）」を削除。
- 全画面の見直し: まとめ画面のリスト選択の「すべてのメモ」が欠けて表示されていた → 「すべて」に。

## v20

- アプリ名を「ヒフミヨ」に変更（画面の名前・ホーム画面に追加したときの名前・パンくず・バックアップのファイル名）。保存データの中身はそのまま（以前のバックアップも読み込める）。
- 文字を X（旧Twitter）と同じ端末標準のゴシック体に統一（題名の明朝体もやめた）。外部フォントの読み込みをやめたので、初回やオフラインでも同じ見た目に。行間・字間を見直し（本文1.85／入力欄1.8、行どうしに少し間）。
- まとめ: リスト・期間に「未選択」（絞り込みなし）。キーワードなしでまとめた場合は「関連部分だけ／全文」を出さない（全文になる）。
- 検索画面のタブを横スライドで切り替えるとき、指に合わせて一覧が動き、離すと滑らかに次のタブへ（足りなければ元に戻る）。
- 閲覧画面: 上部バーに題名・ジャンル・タグを表示し、「メモを読む」の文字を削除。パンくずは重複する今の画面名を省き、必要なときだけ表示。
- 全画面をライト／ダークで確認し、ごちゃつき・ズレなし。
