# Googleドライブ同期の設定（最初に1回だけ）

ヒフミヨのメモを、自分の Googleドライブにも保存できるようにする手順です。
パソコンで行うのがおすすめです（スマホでもできます）。所要時間は 5〜10 分ほどです。

- 保存先は、あなたの Googleドライブにできる **「ヒフミヨ_同期」フォルダ** だけです。
- 同期は、アプリの設定で **「同期」を押してオンにしたときだけ** 動きます。オフのときは何も送りません。
- 料金はかかりません（Google の無料の仕組み「Apps Script」を使います）。

---

## 1. Google Apps Script を開く

1. パソコンのブラウザで https://script.google.com を開き、ふだん使っている Google アカウントでログインします。
2. 左上の **「新しいプロジェクト」** を押します。
3. 左上の「無題のプロジェクト」を押して、名前を **「ヒフミヨ同期」** などに変えておくと分かりやすいです。

## 2. プログラムを貼り付ける

1. 画面中央に最初から入っている文字（`function myFunction() { … }`）を **すべて消します**。
2. GitHub のこのリポジトリの **`gas/Code.gs`** を開き、中身を **すべてコピー** して貼り付けます。
   （GitHub でファイルを開き、右上の「コピー」ボタン（四角が2つ重なったアイコン）で全体をコピーできます）
3. 貼り付けた中の次の行を探します。

   ```
   const KEY = "ここに合言葉";
   ```

   `ここに合言葉` の部分を、**自分で決めた合言葉** に書き換えます（`"` は消さないでください）。
   - 英数字で **12文字以上** がおすすめです（例：`hifumi-2026-umi-yama`）。
   - この合言葉は、あとでアプリにも入力します。メモなどに控えておいてください。
4. 上の **保存ボタン（フロッピーディスクの形）** を押します。

## 3. ウェブアプリとして公開する

1. 右上の青い **「デプロイ」** → **「新しいデプロイ」** を押します。
2. 「種類の選択」の横の **歯車** を押して **「ウェブアプリ」** を選びます。
3. 次のように設定します。
   - 説明：何でもよい（空欄でも可）
   - **次のユーザーとして実行：自分**
   - **アクセスできるユーザー：全員**
     （「全員」にしないとアプリからつながりません。合言葉を知らない人は読み書きできないので安心してください）
4. **「デプロイ」** を押します。
5. 「アクセスを承認」を押し、自分のアカウントを選びます。
   - 「このアプリは Google で確認されていません」と出たら、左下の **「詳細」** → **「ヒフミヨ同期（安全ではないページ）に移動」** を押します。
     これは「自分で作ったプログラムを自分で使う」ときに必ず出る表示です。
   - 「許可」を押します（Googleドライブのファイルを作成・編集する許可です）。
6. 完了画面の **「ウェブアプリ」の URL**（`https://script.google.com/macros/s/……/exec`）の横の **「コピー」** を押します。

## 4. アプリに入力して同期をオンにする

1. ヒフミヨを開き、右上の **設定（歯車）** を押します。
2. 「Googleドライブ同期」の **「接続の設定」** を開き、
   - **接続先のURL** に、3-6 でコピーした URL を貼り付けます。
   - **合言葉** に、2-3 で決めた合言葉を入れます。
3. **「同期」** を押します。「同期しました」と出れば完了です。
   ボタンが緑の **「同期中（押すとオフ）」** になり、以後はメモを保存するたびに自動でドライブへ送ります。
   もう一度押すまで、オンのまま（アプリを閉じても）続きます。

## 別の端末・入れ直したとき

iPhone でアプリを入れ直したときや、機種変更したとき、PC でも使いたいときは、
その端末のヒフミヨで **4. と同じ URL と合言葉を入れて「同期」を押す** だけで、メモ（添付ファイルも）が戻ります。
複数の端末で同期をオンにしておくと、どの端末で書いたメモも、ほかの端末に届きます（新しく直した方が残ります）。

## 困ったとき

| 表示 | 原因と対処 |
|---|---|
| 合言葉が違います | アプリの合言葉と、`Code.gs` の `KEY` が同じか確かめてください。`KEY` を直したら、5. の手順で新しい版を公開し直します。 |
| 接続先の応答を読めませんでした | URL が `/exec` で終わっているか、「アクセスできるユーザー：全員」になっているか確かめてください。 |
| 電波がないため、つながったら同期します | 電波が戻ると自動で送ります。 |

## 5. プログラムを直したとき（めったにありません）

`Code.gs` を書き換えたときは、**「デプロイ」→「デプロイを管理」→ 鉛筆（編集）→ バージョン「新しいバージョン」→「デプロイ」** を押します。
URL は変わらないので、アプリの設定はそのままで使えます。

## ドライブの中身

- `ヒフミヨ_同期/data.json` … メモ・リストのデータ（最新）
- `ヒフミヨ_同期/data-日付.json` … 毎日の控え（30日分。古いものは自動でゴミ箱へ）
- `ヒフミヨ_同期/files/` … 添付ファイル（写真など）
